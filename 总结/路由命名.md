# Vue Router 路由命名

## 一、路由的两种配置方式

### 1. 路径路由（path）

```javascript
{
    path: "/test",    // 通过路径访问
    component: () => import("@/views/Test.vue")
}
```

访问方式：`http://localhost:5173/test`

### 2. 命名路由（name）

```javascript
{
    path: "/test",
    name: "test",     // 通过名称访问
    component: () => import("@/views/Test.vue")
}
```

访问方式：通过 `name` 跳转

---

## 二、两种方式的区别

| | 路径路由 | 命名路由 |
|--|----------|----------|
| 配置 | 只有 `path` | 有 `name` |
| 访问方式 | 直接输入URL | 通过名称跳转 |
| 跳转写法 | `router.push('/test')` | `router.push({ name: 'test' })` |
| URL变化时 | 所有引用都要改 | 只改路由配置，其他不动 |
| 推荐程度 | ⭐⭐ | ⭐⭐⭐⭐⭐ |

---

## 三、跳转方式对比

### 1. 路径跳转

```javascript
// 直接写路径
router.push('/test')
router.push('/test1')

// 如果路径改了，所有地方都要改！
```

### 2. 命名跳转

```javascript
// 通过名称跳转
router.push({ name: 'test' })
router.push({ name: 'test1' })

// 路径改了，这里不用动！
```

### 3. RouterLink 中使用

```vue
<template>
    <!-- 路径跳转 -->
    <RouterLink to="/test">测试</RouterLink>

    <!-- 命名跳转（推荐） -->
    <RouterLink :to="{ name: 'test' }">测试</RouterLink>
</template>
```

---

## 四、为什么推荐命名路由？

### 场景：路径需要修改

**使用路径路由：**
```javascript
// 原来
{ path: "/test", component: Test }

// 需要改成 /my-test
{ path: "/my-test", component: Test }

// 所有跳转的地方都要改！
router.push('/test')        // ❌ 要改成 '/my-test'
<RouterLink to="/test">     // ❌ 要改成 '/my-test'
```

**使用命名路由：**
```javascript
// 原来
{ path: "/test", name: "test", component: Test }

// 需要改成 /my-test
{ path: "/my-test", name: "test", component: Test }

// 跳转的地方不用改！
router.push({ name: 'test' })           // ✅ 不用改
<RouterLink :to="{ name: 'test' }">    // ✅ 不用改
```

## 五、完整示例

### 路由配置

```javascript
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
    {
        path: "/",
        name: "home",
        component: () => import("@/views/Home.vue")
    },
    {
        path: "/test",
        name: "test",
        component: () => import("@/views/Test.vue")
    },
    {
        path: "/test1",
        name: "test1",
        component: () => import("@/views/Test1.vue")
    }
]

const router = createRouter({
    history: createWebHistory(),
    routes
})

export default router
```

### 导航组件

```vue
<template>
    <nav>
        <!-- 推荐：命名路由 -->
        <RouterLink :to="{ name: 'home' }">首页</RouterLink>
        <RouterLink :to="{ name: 'test' }">测试</RouterLink>
        <RouterLink :to="{ name: 'test1' }">测试1</RouterLink>
    </nav>
</template>
```

### 编程式导航

```vue
<script setup>
import { useRouter } from 'vue-router'

const router = useRouter()

// 推荐：命名路由
const goTest = () => {
    router.push({ name: 'test' })
}

const goTest1 = () => {
    router.push({ name: 'test1' })
}
</script>
```

## 六、路径大小写问题

### 默认行为：不区分大小写

Vue Router 4 默认**大小写不敏感**：

```
配置 path: "/test"

/test   → ✅ 匹配
/Test   → ✅ 也能匹配（不区分大小写）
/TEST   → ✅ 也能匹配
```

### 开启大小写敏感

```javascript
const router = createRouter({
    history: createWebHistory(),
    strict: true,        // 启用严格模式
    routes: [
        {
            path: "/test",
            name: "test",
            component: () => import("@/views/Test.vue"),
            sensitive: true  // 区分大小写
        }
    ]
})
```

开启后：
```
/test   → ✅ 匹配
/Test   → ❌ 不匹配
/TEST   → ❌ 不匹配
```

### 对比表

| 配置 | /test | /Test | /TEST |
|------|-------|-------|-------|
| 默认（不区分） | ✅ | ✅ | ✅ |
| `sensitive: true` | ✅ | ❌ | ❌ |
| `strict: true` | ✅ | ✅ | ✅ |

### 一般不需要改

| 场景 | 建议 |
|------|------|
| 大小写不敏感（默认） | ✅ 推荐，用户体验好 |
| 大小写敏感 | 很少用，除非有特殊需求 |

## 七、路由禁用

### 1. 禁用 RouterLink 的默认行为

```vue
<template>
    <!-- 禁用后不能点击，样式变灰 -->
    <RouterLink :to="{ name: 'test' }" disabled>测试</RouterLink>
</template>

<style>
/* 禁用样式 */
a.router-link-active.disabled {
    pointer-events: none;  /* 禁止点击 */
    opacity: 0.5;          /* 半透明 */
    cursor: not-allowed;   /* 禁止光标 */
}
</style>
```

### 2. 条件禁用

```vue
<template>
    <RouterLink
        :to="{ name: 'test' }"
        :class="{ disabled: !isLogin }"
    >
        测试
    </RouterLink>
</template>

<script setup>
import { ref } from 'vue'
const isLogin = ref(false)
</script>

<style>
.disabled {
    pointer-events: none;
    opacity: 0.5;
}
</style>
```

### 3. 路由守卫禁用（更推荐）

```javascript
// router/index.js
const routes = [
    {
        path: "/admin",
        name: "admin",
        component: () => import("@/views/Admin.vue"),
        meta: { requiresAuth: true }  // 需要登录
    }
]

// 全局前置守卫
router.beforeEach((to, from, next) => {
    const isLogin = false  // 判断是否登录

    if (to.meta.requiresAuth && !isLogin) {
        // 未登录，跳转登录页
        next({ name: 'login' })
    } else {
        next()  // 放行
    }
})
```

### 4. 完整示例：禁用+样式

```vue
<template>
    <nav>
        <RouterLink :to="{ name: 'home' }">首页</RouterLink>

        <!-- 未登录时禁用 -->
        <RouterLink
            :to="{ name: 'admin' }"
            :class="{ disabled: !isLogin }"
            @click.prevent="handleClick"
        >
            管理后台
        </RouterLink>
    </nav>
</template>

<script setup>
import { ref } from 'vue'
import { useRouter } from 'vue-router'

const router = useRouter()
const isLogin = ref(false)

const handleClick = () => {
    if (!isLogin.value) {
        alert('请先登录！')
        router.push({ name: 'login' })
    }
}
</script>

<style scoped>
.disabled {
    pointer-events: none;
    opacity: 0.5;
    cursor: not-allowed;
}
</style>
```

## 八、总结

| 要点 | 说明 |
|------|------|
| 路径路由 | 直接写 `path`，通过URL访问 |
| 命名路由 | 配置 `name`，通过名称跳转 |
| 推荐 | ✅ 使用命名路由，维护更方便 |
| 原因 | 路径变化时，只需改配置，不用改跳转代码 |
| 大小写 | 默认不区分，`sensitive: true` 可开启区分 |
| 禁用方式 | CSS禁用 / 路由守卫禁用 |

### 最佳实践

```javascript
// ✅ 推荐：同时配置 path 和 name
{
    path: "/test",
    name: "test",
    component: () => import("@/views/Test.vue")
}

// ❌ 不推荐：只有 path
{
    path: "/test",
    component: () => import("@/views/Test.vue")
}
```
