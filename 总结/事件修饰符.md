# Vue 事件修饰符

## 一、什么是事件修饰符

事件修饰符用于对事件触发进行特殊处理，以点 `.` 开头的指令后缀。

```vue
<!-- 语法 -->
<元素 @事件名.修饰符="处理函数">
```

---

## 二、常用事件修饰符

### 1. `.once` — 只触发一次

```vue
<!-- 只能点击一次 -->
<button @click.once="handleClick">只能点一次</button>

<!-- 子组件事件也只能触发一次 -->
<MyComponent @some-event.once="callback" />
```

**应用场景**：
- 提交按钮（防止重复提交）
- 初始化操作
- 一次性确认弹窗

### 2. `.prevent` — 阻止默认行为

```vue
<!-- 阻止表单默认提交 -->
<form @submit.prevent="onSubmit">
  <button type="submit">提交</button>
</form>

<!-- 阻止链接跳转 -->
<a @click.prevent="handleClick" href="#">链接</a>
```

**常用场景**：
- 表单提交
- 链接点击
- 右键菜单

### 3. `.stop` — 阻止事件冒泡

```vue
<!-- 阻止事件传播到父元素 -->
<div @click="handleParent">
  <button @click.stop="handleChild">点击</button>
</div>
```

**原理**：
```html
<!-- 点击按钮时，handleChild 会执行，handleParent 不会 -->
<div @click="handleParent">
  <button @click.stop="handleChild">按钮</button>
</div>
```

### 4. `.self` — 只有事件源是自身才触发

```vue
<!-- 只有点击 div 本身才触发，点击子元素不触发 -->
<div @click.self="handleClick">
  <button>子元素</button>
</div>
```

### 5. `.capture` — 事件捕获阶段触发

```vue
<!-- 在捕获阶段触发（从外到内） -->
<div @click.capture="handleCapture">
  <button @click="handleClick">按钮</button>
</div>
```

**事件流顺序**：
- 捕获阶段：外 → 内
- 目标阶段：目标元素
- 冒泡阶段：内 → 外

### 6. `.passive` — 不阻止默认行为（提升性能）

```vue
<!-- 适用于触摸事件，提升滚动性能 -->
<div @touchmove.passive="handleTouch">内容</div>
```

---

## 三、修饰符链式调用

修饰符可以串联使用，顺序很重要：

```vue
<!-- 先阻止冒泡，再阻止默认行为 -->
<a @click.stop.prevent="handleClick">链接</a>

<!-- 先阻止默认行为，再阻止冒泡 -->
<a @click.prevent.stop="handleClick">链接</a>
```

**注意**：修饰符的顺序会影响行为！

## 四、按键修饰符

### 常用按键

```vue
<!-- 回车键 -->
<input @keyup.enter="submit" />

<!-- ESC 键 -->
<input @keyup.esc="cancel" />

<!-- Tab 键 -->
<input @keyup.tab="handleTab" />

<!-- Delete 键 -->
<input @keyup.delete="handleDelete" />
```

### 系统按键修饰符

```vue
<!-- Ctrl + 点击 -->
<button @click.ctrl="handleCtrlClick">按钮</button>

<!-- Alt + 点击 -->
<button @click.alt="handleAltClick">按钮</button>

<!-- Shift + 点击 -->
<button @click.shift="handleShiftClick">按钮</button>

<!-- Meta 键 (Windows 键 / Mac Command 键) -->
<button @click.meta="handleMetaClick">按钮</button>
```

### 组合按键

```vue
<!-- Ctrl + S -->
<input @keyup.ctrl.s="save" />

<!-- Alt + Enter -->
<input @keyup.alt.enter="submit" />
```

## 五、鼠标按键修饰符

<!-- 右键点击 -->

## 六、总结对比表

| 修饰符 | 作用 | 使用场景 |
|--------|------|----------|
| `.once` | 只触发一次 | 防重复提交、一次性操作 |
| `.prevent` | 阻止默认行为 | 表单提交、链接跳转 |
| `.stop` | 阻止冒泡 | 防止事件传播 |
| `.self` | 仅自身触发 | 精确控制事件源 |
| `.capture` | 捕获阶段触发 | 提前处理事件 |
| `.passive` | 不阻止默认 | 触摸事件优化 |
| `.enter` | 回车键 | 表单提交、搜索 |
| `.esc` | ESC 键 | 取消、关闭 |
| `.ctrl` | Ctrl 键 | 组合快捷键 |
| `.alt` | Alt 键 | 组合快捷键 |
| `.shift` | Shift 键 | 组合快捷键 |
| `.meta` | Meta 键 | Windows/Mac 组合键 |

## 七、最佳实践

### 1. 提交按钮防重复

```vue
<button @click.once="submit">提交</button>
```

### 2. 表单提交

```vue
<form @submit.prevent="handleSubmit">
  <input type="text" />
  <button type="submit">提交</button>
</form>
```

### 3. 精确控制点击

```vue
<!-- 只有点击 div 本身才触发，点击子元素不触发 -->
<div @click.self="handleClick">
  <span>内容</span>
</div>
```

### 4. 键盘快捷键

```vue
<input @keyup.ctrl.s="save" />
<input @keyup.esc="cancel" />
```

## 八、完整示例

```vue
<template>
  <!-- 防重复提交 -->
  <button @click.once="submit">提交订单</button>

  <!-- 表单 -->
  <form @submit.prevent="handleSubmit">
    <input v-model="username" @keyup.enter="handleSubmit" />
    <button type="submit">登录</button>
  </form>

  <!-- 组合按键 -->
  <div @click.ctrl="handleCtrlClick">
    按住 Ctrl 点击
  </div>
</template>

<script setup>
import { ref } from 'vue'

const username = ref('')

const submit = () => {
  console.log('提交（只执行一次）')
}

const handleSubmit = () => {
  console.log('表单提交')
}

const handleCtrlClick = () => {
  console.log('Ctrl + 点击')
}
</script>
```

## 九、注意事项

1. **顺序问题**：`.prevent.stop` 和 `.stop.prevent` 行为可能不同
2. **`.once` 只对事件绑定有效**：不影响 `$emit`
3. **修饰符不可逆**：使用后无法在运行时取消
4. **性能考虑**：`.passive` 只用于触摸事件，不要滥用
