# Vue 组件事件详解

## 一、触发与监听事件

### 1. 基本用法

**子组件触发事件**：
```vue
<template>
  <!-- 使用 $emit 触发事件 -->
  <button @click="$emit('someEvent')">点击我</button>
</template>
```

**父组件监听事件**：
```vue
<template>
  <!-- 使用 @ 或 v-on 监听事件 -->
  <MyComponent @some-event="callback" />
</template>
```

### 2. 事件命名规则

| 位置 | 命名格式 | 示例 |
|------|----------|------|
| 子组件触发 | camelCase | `$emit('someEvent')` |
| 父组件监听 | kebab-case | `@some-event="callback"` |

```vue
<!-- 子组件 -->
<button @click="$emit('increaseBy', 1)">+1</button>

<!-- 父组件 -->
<MyComponent @increase-by="handleIncrease" />
```

### 3. 事件修饰符

```vue
<!-- .once 修饰符：只触发一次 -->
<MyComponent @some-event.once="callback" />
```

## 二、事件参数

### 1. 传递参数

**子组件**：
```vue
<template>
  <!-- 触发事件时传递参数 -->
  <button @click="$emit('increaseBy', 1)">+1</button>
  <button @click="$emit('increaseBy', 5)">+5</button>
</template>
```

**父组件**：
```vue
<template>
  <!-- 方式1：内联箭头函数 -->
  <MyButton @increase-by="(n) => count += n" />

  <!-- 方式2：方法处理函数 -->
  <MyButton @increase-by="increaseCount" />
</template>

<script setup>
import { ref } from 'vue'
const count = ref(0)

// 方式2的处理函数
function increaseCount(n) {
  count.value += n
}
</script>
```

### 2. 传递多个参数

```vue
<!-- 子组件 -->
<button @click="$emit('foo', 1, 2, 3)">传递多个参数</button>

<!-- 父组件 -->
<MyComponent @foo="(a, b, c) => console.log(a, b, c)" />
```

## 三、声明触发的事件（defineEmits）

### 1. 基本声明

```vue
<script setup>
// 声明组件要触发的事件
defineEmits(['inFocus', 'submit'])
</script>
```

### 2. 使用 emit 函数

```vue
<script setup>
// $emit 不能在 script setup 中使用
// 需要用 defineEmits 返回的 emit 函数
const emit = defineEmits(['inFocus', 'submit'])

function buttonClick() {
  emit('submit')  // ✅ 正确
  // $emit('submit')  // ❌ 错误：不能在 script setup 中使用
}
</script>
```

### 3. 完整示例

```vue
<template>
  <button @click="handleSubmit">提交</button>
</template>

<script setup>
const emit = defineEmits(['submit', 'update'])

const handleSubmit = () => {
  emit('submit', { email: 'test@test.com', password: '123' })
}
</script>
```

## 四、两种声明方式对比

### 1. script setup 方式（推荐）

```vue
<script setup>
const emit = defineEmits(['submit', 'update'])

function handleClick() {
  emit('submit')
}
</script>
```

### 2. setup 函数方式

```javascript
export default {
  emits: ['submit', 'update'],
  setup(props, ctx) {
    ctx.emit('submit')
  }
}

// 或者解构
export default {
  emits: ['submit', 'update'],
  setup(props, { emit }) {
    emit('submit')
  }
}
```

## 五、事件校验

### 1. 对象形式 + 校验函数

```vue
<script setup>
const emit = defineEmits({
  // 不校验
  click: null,

  // 校验 submit 事件
  submit: ({ email, password }) => {
    if (email && password) {
      return true    // 校验通过
    } else {
      console.warn('Invalid submit event payload!')
      return false   // 校验失败
    }
  }
})

function submitForm(email, password) {
  emit('submit', { email, password })
}
</script>
```

### 2. 校验函数解析

```javascript
const emit = defineEmits({
  submit: ({ email, password }) => {
    //                  ↑ 解构 emit 传入的参数
    if (email && password) {
      return true    // 合法，事件可以发送
    } else {
      return false   // 不合法，阻止事件发送
    }
  }
})
```

| 部分 | 含义 |
|------|------|
| `submit` | 通道名称 |
| `({ email, password })` | 解构 emit 传入的 payload |
| `return true/false` | 校验结果 |

## 六、TypeScript 类型标注

### 1. 对象形式 + TypeScript

```typescript
<script setup lang="ts">
const emit = defineEmits({
  submit(payload: { email: string, password: string }) {
    //      ↑ 参数类型定义
    if (email && password) {
      return true
    } else {
      return false
    }
  }
})
</script>
```

### 2. 纯类型标注

```typescript
<script setup lang="ts">
const emit = defineEmits<{
  (e: 'change', id: number): void
  (e: 'update', value: string): void
}>()
</script>
```

### 3. TypeScript 优势

| 特性 | JavaScript | TypeScript |
|------|-----------|------------|
| 类型检查 | ❌ 运行时 | ✅ 编译时 |
| 智能提示 | ❌ 无 | ✅ 有 |
| 代码补全 | ❌ 无 | ✅ 有 |

## 七、重要特性

### 1. 事件没有冒泡机制

```vue
<!-- ❌ 不会冒泡到祖父组件 -->
<GrandParent @some-event="callback">
  <Parent>
    <Child @click="$emit('someEvent')" />
  </Parent>
</GrandParent>

<!-- ✅ 只监听直接子组件 -->
<Child @some-event="callback" />
```

### 2. 原生事件覆盖

```vue
<!-- 如果原生事件名在 emits 中声明，只监听组件触发的事件 -->
<MyComponent @click="callback" />

<!-- 监听原生 click 事件需要使用 .native 修饰符 -->
<MyComponent @click.native="callback" />
```

## 八、最佳实践

### 1. 完整声明所有事件

```vue
<script setup>
// ✅ 推荐：完整声明
const emit = defineEmits(['submit', 'update', 'delete'])

// ❌ 不推荐：不声明
// emit 直接使用，没有类型检查
</script>
```

### 2. 使用校验函数

```vue
<script setup>
const emit = defineEmits({
  // 校验参数
  'update-count': (value) => typeof value === 'number' && value > 0,
  'update-name': (name) => typeof name === 'string' && name.length > 0
})
</script>
```

### 3. 命名规范

```vue
<!-- 子组件：camelCase -->
<button @click="$emit('updateCount', 1)">+1</button>

<!-- 父组件：kebab-case -->
<MyComponent @update-count="handleUpdate" />
```

## 九、完整示例

### 子组件 MyButton.vue

```vue
<template>
  <button @click="handleClick">
    {{ text }}
  </button>
</template>

<script setup>
defineProps({
  text: {
    type: String,
    default: '按钮'
  }
})

const emit = defineEmits({
  // 校验函数
  'update-count': (value) => typeof value === 'number' && value > 0
})

const handleClick = () => {
  emit('update-count', 1)
}
</script>
```

### 父组件 App.vue

```vue
<template>
  <div>
    <p>计数：{{ count }}</p>
    <MyButton 
      text="+1" 
      @update-count="(n) => count += n" 
    />
    <MyButton 
      text="+5" 
      @update-count="(n) => count += n" 
    />
  </div>
</template>

<script setup>
import { ref } from 'vue'
import MyButton from './components/MyButton.vue'

const count = ref(0)
</script>
```

## 十、总结对比

| 功能 | 写法 | 说明 |
|------|------|------|
| 触发事件 | `$emit('name', payload)` | 模板中使用 |
| 监听事件 | `@name="callback"` | 父组件使用 |
| 声明事件 | `defineEmits(['name'])` | script setup 中 |
| 事件校验 | `defineEmits({ name: 校验函数 })` | 带校验 |
| TypeScript | `defineEmits<{ (e: 'name', payload: type): void }>()` | 类型标注 |

### 记忆口诀

```
子组件 $emit 触发
父组件 @ 监听
script setup 用 defineEmits
校验用对象形式
```
