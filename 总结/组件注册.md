# Vue 组件注册

## 一、组件注册概述

一个 Vue 组件在使用前需要先被"注册"，这样 Vue 才能在渲染模板时找到其对应的实现。

组件注册有两种方式：
- **全局注册**
- **局部注册**

---

## 二、全局注册

使用 Vue 应用实例的 `.component()` 方法，让组件在当前 Vue 应用中**全局可用**。

### 1. 基本语法

```javascript
import { createApp } from 'vue'

const app = createApp({})

app.component(
  // 注册的名字
  'MyComponent',
  // 组件的实现
  {
    /* ... */
  }
)
```

### 2. 注册单文件组件

```javascript
import MyComponent from './App.vue'

app.component('MyComponent', MyComponent)
```

### 3. 链式调用

```javascript
app
  .component('ComponentA', ComponentA)
  .component('ComponentB', ComponentB)
  .component('ComponentC', ComponentC)
```

### 4. 使用

全局注册的组件可以在此应用的**任意组件**的模板中使用：

```vue
<!-- 这在当前应用的任意组件中都可用 -->
<ComponentA/>
<ComponentB/>
<ComponentC/>
```

所有的子组件也可以使用全局注册的组件，这意味着这三个组件也都可以在彼此内部使用。

### 5. 完整示例

```javascript
// main.js
import { createApp } from 'vue'
import App from './App.vue'
import MyButton from '@/components/MyButton.vue'
import MyCard from '@/components/MyCard.vue'

const app = createApp(App)

// 全局注册
app.component('MyButton', MyButton)
app.component('MyCard', MyCard)

app.mount('#app')
```

```vue
<!-- 任意组件中都能直接使用 -->
<template>
    <MyButton>点击</MyButton>
    <MyCard>内容</MyCard>
</template>
```

## 三、局部注册

局部注册的组件需要在使用它的父组件中**显式导入**，并且只能在**该父组件**中使用。

### 1. 使用 `<script setup>`（推荐）

```vue
<script setup>
import ComponentA from './ComponentA.vue'
</script>

<template>
  <ComponentA />
</template>
```

导入的组件可以直接在模板中使用，**无需注册**。

### 2. 不使用 `<script setup>`

```javascript
import ComponentA from './ComponentA.js'

export default {
  components: {
    ComponentA  // 等价于 ComponentA: ComponentA
  },
  setup() {
    // ...
  }
}
```

### 3. 完整示例

```vue
<template>
    <div>
        <h1>父组件</h1>
        <ComponentA />  <!-- ✅ 可以使用 -->
        <ComponentB />  <!-- ✅ 可以使用 -->
    </div>
</template>

<script setup>
import ComponentA from './ComponentA.vue'
import ComponentB from './ComponentB.vue'
// 导入即注册，不需要 components 选项
</script>
```

```vue
<!-- ComponentA.vue 中不能使用 ComponentB -->
<template>
    <div>
        <ComponentB />  <!-- ❌ 不能使用，因为没有导入 -->
    </div>
</template>
```

## 四、全局注册 vs 局部注册

| | 全局注册 | 局区注册 |
|--|----------|----------|
| 注册方式 | `app.component()` | `import` 导入 |
| 使用范围 | 应用内任意组件 | 只能在导入的父组件中 |
| Tree-shaking | ❌ 无法自动移除 | ✅ 可以自动移除 |
| 依赖关系 | 不明确 | 明确 |
| 推荐场景 | 全局通用组件 | 大部分场景 |

### 全局注册的缺点

1. **无法 tree-shaking**
   - 全局注册但没有被使用的组件无法在生产打包时被自动移除
   - 仍然会出现在打包后的 JS 文件中

2. **依赖关系不明确**
   - 在父组件中使用子组件时，不太容易定位子组件的实现
   - 和使用过多的全局变量一样，可能会影响应用长期的可维护性

### 局部注册的优点

1. **依赖关系明确**
   - 父组件中显式导入子组件，一目了然

2. **Tree-shaking 友好**
   - 没有被使用的组件不会被打包

## 五、组件名格式

### 1. PascalCase（推荐）

在整个指引中，我们都使用 **PascalCase** 作为组件名的注册格式：

```javascript
// ✅ 推荐
app.component('MyComponent', MyComponent)
app.component('MyButton', MyButton)
```

原因：
- PascalCase 是合法的 JavaScript 标识符
- 在 JavaScript 中导入和注册组件都很容易
- IDE 也能提供较好的自动补全
- `<PascalCase />` 在模板中更明显地表明这是一个 Vue 组件，而不是原生 HTML 元素
- 能够将 Vue 组件和自定义元素 (web components) 区分开来

### 2. kebab-case

Vue 支持将模板中使用 **kebab-case** 的标签解析为使用 PascalCase 注册的组件：

```javascript
// 注册
app.component('MyComponent', MyComponent)
```

```vue
<!-- 以下两种写法都可以 -->
<MyComponent />
<my-component />
```

### 3. 对比表

| 注册名 | 模板中使用 | 说明 |
|--------|-----------|------|
| `MyComponent` | `<MyComponent />` | PascalCase，推荐 |
| `MyComponent` | `<my-component />` | kebab-case，也可以 |
| `my-component` | `<my-component />` | kebab-case 注册 |

## 六、最佳实践

### 1. 全局注册

适用于**全局通用组件**（如按钮、弹窗、加载动画等）：

```javascript
// main.js
app.component('MyButton', MyButton)
app.component('MyModal', MyModal)
app.component('MyLoading', MyLoading)
```

### 2. 局部注册

适用于**大部分场景**：

```vue
<script setup>
import UserCard from './UserCard.vue'
import SearchBar from './SearchBar.vue'
// 导入即注册
</script>

<template>
    <UserCard />
    <SearchBar />
</template>
```

### 3. 组件名规范

```javascript
// ✅ 推荐：PascalCase
import MyComponent from './MyComponent.vue'
app.component('MyComponent', MyComponent)

// ❌ 不推荐：kebab-case
import my-component from './my-component.vue'
```

---

## 七、总结

| 要点 | 说明 |
|------|------|
| 全局注册 | `app.component()`，全局可用，但无法 tree-shaking |
| 局部注册 | `import` 导入，只能在父组件中用，推荐使用 |
| 组件名格式 | 推荐 PascalCase，kebab-case 也可以 |
| `<script setup>` | 导入即注册，不需要 `components` 选项 |
| 选项式 API | 需要在 `components` 中显式注册 |

### 注册方式选择

| 组件类型 | 推荐方式 |
|----------|----------|
| 全局通用组件（按钮、弹窗等） | 全局注册 |
| 业务组件（卡片、表单等） | 局部注册 |
| 页面组件 | 局部注册 |
