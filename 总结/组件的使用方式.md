# Vue 组件的使用方式

## 第一种：选项式API中使用组件

### 步骤说明

1. **导入组件**：使用 `import` 导入子组件
2. **注册组件**：在 `components` 选项中注册
3. **使用组件**：在模板中以标签形式使用

### 代码示例

```vue
<template>
    <h1>我是系统首页</h1>

    <!-- 3. 模板中使用组件 -->
    <TestButton/>
</template>

<script>
// 1. 导入组件
import TestButton from '@/components/TestButton.vue';

// 2. 注册组件
export default {
    components: {
        TestButton  // 等价于 TestButton: TestButton
    }
}
</script>
```

### 关键点

- `@` 符号代表 `src` 目录，是 Vite/Webpack 的路径别名
- `components` 对象中的键名就是模板中使用的标签名
- 如果组件名和导入名相同，可以简写（如 `TestButton`）

---

## 第二种：组合式API中使用组件

### 代码示例

```vue
<template>
    <TestButton/>
</template>

<script setup>
// 只需要导入，不需要注册！
import TestButton from '@/components/TestButton.vue'
</script>
```

### 关键点

- `<script setup>` 语法糖，导入即注册
- 不需要 `components` 选项
- 更简洁，推荐使用

---

## 第三种：全局注册组件

### 代码示例

```javascript
// main.js
import { createApp } from 'vue'
import App from './App.vue'
import TestButton from '@/components/TestButton.vue'

const app = createApp(App)

// 全局注册，所有组件都能用
app.component('TestButton', TestButton)

app.mount('#app')
```

### 使用

```vue
<!-- 任何组件中都能直接使用，不需要导入 -->
<template>
    <TestButton/>
</template>
```

### 关键点

- 在 `main.js` 中用 `app.component()` 注册
- 注册后所有组件都能直接使用
- 适合全局通用组件（如按钮、弹窗等）
