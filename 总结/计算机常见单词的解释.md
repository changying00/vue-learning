# 计算机常见英文单词解释

## 一、网络通信



### Vue/Emit 中

```javascript
// payload 指事件携带的数据
emit('count-num', currentNum.value)  // currentNum.value 就是 payload
```



| 英文          | 中文翻译      | 含义                                     |
| ------------- | ------------- | ---------------------------------------- |
| **Payload**   | 有效载荷/负载 | 数据包中的实际数据部分（不含头部信息）  |
| **Header**    | 头部          | 数据包的元数据信息（来源、目标、类型等） |
| **Request**   | 请求          | 客户端向服务器发送的请求                 |
| **Response**  | 响应          | 服务器返回给客户端的数据                 |
| **Endpoint**  | 端点          | API 的访问地址                           |
| **Protocol**  | 协议          | 通信规则（如 HTTP、HTTPS、TCP）          |
| **Latency**   | 延迟          | 数据传输所需时间                         |
| **Bandwidth** | 带宽          | 单位时间内传输的最大数据量               |

## 二、HTTP 请求相关


| 英文            | 中文翻译      | 含义                                                |
| --------------- | ------------- | --------------------------------------------------- |
| **Method**      | 方法          | 请求方式（GET、POST、PUT、DELETE）                  |
| **Status Code** | 状态码        | 服务器响应状态（200成功、404未找到、500服务器错误） |
| **Body**        | 请求体/响应体 | 发送或接收的数据内容                                |
| **Query**       | 查询参数      | URL 中的参数（?key=value）                          |
| **Params**      | 路径参数      | URL 路径中的参数（/user/:id）                       |
| **Headers**     | 请求头        | 附加的元数据（Content-Type、Authorization）         |
| **Cookie**      | Cookie        | 浏览器存储的小型数据                                |
| **Token**       | 令牌          | 身份验证凭证                                        |
