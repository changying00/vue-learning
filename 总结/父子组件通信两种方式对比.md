# 父子组件通信两种方式对比

## 一、两种方式概述

| 方式 | 写法 | 特点 |
|------|------|------|
| **方式1** | `:prop + @event` | 单向数据流 + 事件通信 |
| **方式2** | `v-model` | 双向绑定 |

---

## 二、方式1：:prop + @event（推荐用于组件通信）

### 父组件

```vue
<template>
  <!-- 传递 prop + 监听事件 -->
  <MyComponent :num="3" @count-num="(n) => countNum = n" />
  <h1>{{ countNum }}</h1>
</template>

<script setup>
import { ref } from 'vue'
import MyComponent from './components/MyComponent.vue'

const countNum = ref(0)
</script>
```

### 子组件

```vue
<template>
  <h1>{{ num }}</h1>
  <button @click="countnum">+1</button>
</template>

<script setup>
import { ref } from 'vue'

const props = defineProps({
  num: {
    type: Number,
    required: true
  }
})

const emit = defineEmits(['count-num'])

const currentNum = ref(props.num)

const countnum = () => {
  currentNum.value++
  emit('count-num', currentNum.value)
}
</script>
```

### 数据流

```
父组件 num=3
    ↓
子组件 props.num = 3
    ↓
子组件 currentNum = 3 → 4 → 5 → 6
    ↓
emit('count-num', 4/5/6)
    ↓
父组件 countNum = 4/5/6
```

## 三、方式2：v-model（推荐用于表单绑定）

### 父组件

```vue
<template>
  <!-- v-model 双向绑定 -->
  <MyComponent v-model:num="countNum" />
  <h1>{{ countNum }}</h1>
</template>

<script setup>
import { ref } from 'vue'
import MyComponent from './components/MyComponent.vue'

const countNum = ref(3)
</script>
```

### 子组件

```vue
<template>
  <h1>{{ num }}</h1>
  <button @click="countnum">+1</button>
</template>

<script setup>
import { ref } from 'vue'

const props = defineProps({
  num: {
    type: Number,
    required: true
  }
})

// 必须使用 'update:xxx' 格式
const emit = defineEmits(['update:num'])

const countnum = () => {
  emit('update:num', props.num + 1)
}
</script>
```

### 数据流

```
父组件 countNum = 3
    ↓
子组件 props.num = 3
    ↓
emit('update:num', 4)
    ↓
父组件 countNum = 4（自动更新）
```

## 四、完整对比表

| 对比项 | :prop + @event | v-model |
|--------|---------------|---------|
| **数据流** | 单向：父→子→父 | 双向：自动同步 |
| **事件名** | 自定义（如 `count-num`） | 固定格式（`update:xxx`） |
| **代码量** | 多 | 少 |
| **灵活性** | 高（可自定义事件名） | 低（必须用 `update:xxx`） |
| **可读性** | 高（明确知道数据流向） | 中（隐式双向绑定） |
| **适用场景** | 组件通信、需要处理逻辑 | 表单输入、简单数据同步 |
| **调试难度** | 低（事件明确） | 中（自动触发） |
| **校验处理** | 支持（可在事件中处理） | 不支持（自动触发） |

## 五、代码对比

### 方式1：:prop + @event

```vue
<!-- 父组件 -->
<MyComponent 
  :num="3" 
  @count-num="(n) => countNum = n" 
/>

<!-- 子组件 -->
defineProps({ num: Number })
defineEmits(['count-num'])

emit('count-num', newValue)
```

### 方式2：v-model

```vue
<!-- 父组件 -->
<MyComponent v-model:num="countNum" />

<!-- 子组件 -->
defineProps({ num: Number })
defineEmits(['update:num'])

emit('update:num', newValue)
```

## 六、实际场景示例

### 场景1：计数器组件（推荐方式1）

```vue
<!-- 父组件 -->
<template>
  <Counter 
    :initial="5" 
    @change="(val) => count = val" 
  />
  <p>当前计数：{{ count }}</p>
</template>

<!-- 子组件 Counter.vue -->
<template>
  <button @click="increment">+1</button>
  <span>{{ current }}</span>
</template>

<script setup>
const props = defineProps({ initial: Number })
const emit = defineEmits(['change'])
const current = ref(props.initial)

const increment = () => {
  current.value++
  emit('change', current.value)  // 自定义事件名，语义清晰
}
</script>
```

### 场景2：输入框组件（推荐方式2）

```vue
<!-- 父组件 -->
<template>
  <MyInput v-model:username="username" />
  <p>用户名：{{ username }}</p>
</template>

<!-- 子组件 MyInput.vue -->
<template>
  <input 
    type="text"
    :value="username"
    @input="$emit('update:username', $event.target.value)"
  />
</template>

<script setup>
defineProps({ username: String })
defineEmits(['update:username'])
</script>
```

## 七、什么时候用哪种？

### ✅ 使用 `:prop + @event`

| 场景 | 原因 |
|------|------|
| 需要自定义事件名 | 如 `@count-num`、`@submit` |
| 需要在事件中做处理 | 如校验、日志、异步操作 |
| 数据流需要清晰 | 明确知道数据从哪来、到哪去 |
| 组件通信复杂 | 多个参数、多个事件 |
| 需要传递多个值 | `emit('event', value1, value2)` |

### ✅ 使用 `v-model`

| 场景 | 原因 |
|------|------|
| 表单输入 | 输入框、选择器等 |
| 简单数据同步 | 不需要复杂处理 |
| 代码简洁 | 减少模板代码 |
| Vue 3.4+ | 支持多个 v-model 参数 |

## 八、常见错误

### ❌ 错误：v-model 事件名不是 `update:xxx`

```vue
<!-- 子组件 -->
defineEmits(['count-num'])  // ❌ 错误

<!-- 父组件 -->
<MyComponent v-model:num="countNum" />  // 不会工作
```

### ✅ 正确：v-model 必须用 `update:xxx`

```vue
<!-- 子组件 -->
defineEmits(['update:num'])  // ✅ 正确

<!-- 父组件 -->
<MyComponent v-model:num="countNum" />  // 正常工作
```

### ❌ 错误：:prop + @event 混用 v-model

```vue
<!-- ❌ 错误：混用 -->
<MyComponent :num="countNum" v-model:num="countNum" />

<!-- ✅ 正确：二选一 -->
<MyComponent :num="countNum" @count-num="(n) => countNum = n" />
<!-- 或 -->
<MyComponent v-model:num="countNum" />
```

## 九、总结

### 记忆口诀

```
组件通信用 :prop + @event
表单输入用 v-model
自定义事件名用方式1
简洁绑定用方式2
```

### 选择建议

| 需求 | 推荐方式 |
|------|----------|
| 父子组件通信 | `:prop + @event` |
| 表单双向绑定 | `v-model` |
| 需要自定义事件名 | `:prop + @event` |
| 代码简洁优先 | `v-model` |
| Vue 3.4+ 多参数 | `v-model:xxx` |

### 本质理解

```vue
<!-- v-model 是语法糖 -->
<MyComponent v-model:num="countNum" />

<!-- 等价于 -->
<MyComponent 
  :num="countNum" 
  @update:num="countNum = $event" 
/>
```

**两种方式都是正确的**，根据场景选择最合适的！
